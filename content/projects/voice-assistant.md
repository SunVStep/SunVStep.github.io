**Роль:** исследование и реализация голосового ассистента для операторов роботизированных производственных линий.

**Кратко:** система позволяет операторам отдавать команды, получать уведомления о состоянии линии и безопасно вмешиваться в процесс. Интеграция с PLC и ROS2, система распознавания речи + intent handling, трекинг состояния робота и операторского вмешательства.

**Технологии:** ROS2, Python, PyTorch (на модуле CV/ASR), MQTT/PLC-интеграция, HRI.

**Детали реализации:**

- Архитектура: голосовой модуль (ASR) → intent-mapper → ROS2 action server → safety supervisor (PLC/Siemens) → feedback (TTS + UI).
- Модель ASR: легковесный трансформер для on-device inference, постобработка для повышения точности команд.
- Safety: многослойная проверка команд (operator confirmation, safety supervisor) + логирование событий.
- Результаты: улучшение времени реакции оператора, уменьшение количества аварийных остановов в тестовой зоне (описано в публикации Springer, 2025).
